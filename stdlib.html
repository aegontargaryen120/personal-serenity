Serenity Standard Library

The standard library ships as Serenity source modules (.srn) in the stdlib/ directory. A program at the project root imports a module with:

%import <stdlib/util>
%import <stdlib/string>
%import <stdlib/math>
Note: Serenity has no mutable variables, so functions that accumulate values are written recursively; very large inputs can hit the host recursion limit.

Modules

util.srn

Small identity, boolean, and null helpers. Exported names: identity, not, bool, isNull, notNull, isZero, nonZero, isEmptyText, firstOf, secondOf, toggle, isEqual, isNotEqual, countRange.
