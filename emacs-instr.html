Serenity Mode for Emacs

Major mode for editing the Serenity programming language (.serenity and .srn files).

Features

  • Syntax highlighting — keywords, built-in functions, constants, strings, numbers, function names, and the => arrow
  • Automatic indentation — respects =>, {, and ( openers and }/) closers
  • REPL interaction — interactive $ prompt via comint (run func main() => (...) programs)
  • Compilation — compile to ARM64 assembly or assemble+run with clang (macOS ARM64)
  • Electric pairs — " () {} [] auto-close
  • Imenu — jump to function definitions with imenu (works with Helm, Ivy, Vertico, etc.)
  • Outline / folding — outline-regexp matches func definitions for outline-minor-mode / hideshow

Requirements

  • Emacs 25.1 or later
  • Python 3 (python3 on your PATH)
  • The serenity runner script in the project root (same directory as src/)

Installation

Manual

Copy editors/emacs/serenity-mode.el into your Emacs load path:

mkdir -p ~/.emacs.d/lisp/
cp editors/emacs/serenity-mode.el ~/.emacs.d/lisp/

Add to your init file (~/.emacs or ~/.config/emacs/init.el):

(add-to-list 'load-path "~/.emacs.d/lisp/")
(require 'serenity-mode)

Restart Emacs or evaluate the forms with M-x eval-buffer.

use-package

(use-package serenity-mode
  :load-path "~/.emacs.d/lisp/"
  :mode (("\\.serenity\\'" . serenity-mode)
         ("\\.srn\\'" . serenity-mode)))

Project-local

Place .dir-locals.el in the project root:

((serenity-mode . ((serenity-runner-file . "/path/to/serenity"))))

Configuration

Variable Default Description
serenity-executable "python3" Path to the Python interpreter
serenity-runner-file nil Explicit path to the serenity runner; auto-detected from the project root if nil
serenity-indent-offset 4 Spaces per indentation level

Key Bindings

Major Mode (serenity-mode-map)

Key Command Description
C-c C-c serenity-compile Compile to ARM64 assembly (.s)
C-c C-r serenity-compile-run Compile + assemble + run
C-c C-z serenity-repl Start or switch to the $ REPL
C-c C-e serenity-send-line Send current line to the REPL
C-c C-y serenity-send-region Send active region to the REPL
C-c C-b serenity-send-buffer Send entire buffer to the REPL
C-c C-n serenity-next-function Jump to next func definition
C-c C-p serenity-previous-function Jump to previous func definition

REPL Minor Mode (serenity-repl-minor-mode, active in all Serenity buffers)

Key Command Description
C-c C-s C-e serenity-send-line Send line to REPL
C-c C-s C-b serenity-send-buffer Send buffer to REPL
C-c C-s C-r serenity-send-region Send region to REPL
C-c C-s C-z serenity-repl Start/switch to REPL

Usage

Editing

Open any .serenity or .srn file — the mode activates automatically:

$ emacs hello.serenity
$ emacs stdlib/math.srn

Type freely; after pressing RET, the next line auto-indents according to the block structure. Closing braces and parens dedent automatically when electric-indent-mode re-indents the line after the } or ) is typed.

REPL

Press C-c C-z to start the Serenity REPL. The REPL launches the Serenity runner (python3 serenity) in the project root, giving you the $ prompt.

Note: Serenity programs are function definitions. Each line sent to the REPL must be a complete program, e.g.:

$ func main() => ( println(1 + 2); )
3
$

You can also run the current buffer by compiling with C-c C-c and viewing the *compilation* buffer output.

Compilation

C-c C-c compiles the current .serenity/.srn file to ARM64 assembly (.s):

python3 serenity hello.serenity -o hello.s

C-c C-r compiles, assembles with clang, and runs the binary — useful for testing on macOS ARM64.

Comments

M-; comments or uncomments the current line or region (uses // style).

Navigation

C-c C-n / C-c C-p jump between func definitions. M-x imenu presents a menu of all functions in the current buffer.
